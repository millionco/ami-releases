# Ami

![](https://img.shields.io/badge/macOS-only-blue?style=flat-square)

Ami is an AI-powered coding agent designed for frontend developers. It understands your codebase, generates code from natural language, and shows real-time previews — all in one seamless interface. Describe what you want, see it happen live, review the changes, and commit with confidence.

**Learn more in the [official documentation](https://ami.dev/docs)**.

## Get started

1. Install Ami:

```bash
curl -fsSL https://ami.dev/install | bash
```

> **Note:** Currently, Ami supports macOS only. Linux and WSL are not yet supported.

2. Run Ami in your project directory:

```bash
ami
```

3. On first run, you'll be prompted to log in. Once authenticated, access the full interface at [app.ami.dev](https://app.ami.dev).

4. Verify your installation:

```bash
ami --version
```
